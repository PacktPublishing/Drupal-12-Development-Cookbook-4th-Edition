# Chapter 12 — Theming and Frontend Development

Reference code for Chapter 12 of the *Drupal 12 Development Cookbook* (4th Edition).

The chapter builds a single evolving custom theme, `mytheme`, across seven recipes.
Rather than snapshot the theme once per recipe, this folder is laid out as **one
cumulative theme** that a reader can install and run, with every file authored in
the chapter reproduced verbatim from the chapter's code blocks.

## How `mytheme` is created

The base theme is generated by Drupal's Starterkit theme generator, not written by
hand:

```
ddev exec php web/core/scripts/drupal generate-theme mytheme --name "My Theme" --path themes/custom
```

The files below are the ones **authored on top of** that generated base as the
chapter progresses. `mytheme.info.yml` is included because the recipes edit it
(adding the `global-styling` and `theme-styling` libraries); the generated
`regions:` block is preserved. Per the chapter's Drupal 12 target,
`core_version_requirement` is set to `^12`.

## Notes on cumulative / final versions

- **`mytheme.info.yml`** — Shown incrementally: minimal at R1, `global-styling`
  added at R2, `theme-styling` added at R6. This file merges all three so both
  custom libraries are present, keeping the generated regions block.
- **`vite.config.js`** — R6 introduces the plain Vite config; R7 adds the
  `@tailwindcss/vite` plugin. The final (Tailwind) version is used here.
- **`src/css/main.css`** — R6 starts with CSS variables + a `body` rule; R7
  replaces the whole file with `@import "tailwindcss";`. The final (Tailwind)
  version is used here. (The R6 CSS-variable content is therefore superseded and
  not kept as a separate file.)
- **`alert.twig`** — Intentionally has no co-located CSS file; the chapter styles
  it purely with Tailwind utility classes.

## Files referenced but NOT reproduced (chapter does not print full contents)

- `mytheme.starterkit.yml` — mentioned as an opt-in file that makes the theme

  `generate-theme`, not authored in the chapter, so not reproduced here.
- `dist/` build output (`dist/assets/styles.css`, `dist/assets/main.js`) — emitted
  by `npm run build`, not printed in the chapter. Referenced by
  `mytheme.libraries.yml` but generated at build time.
- `.vite/manifest.json` and the `drupal/vite` HMR variant — described in R6
  "There's more" as an alternative setup; not part of the primary reproduced code.
